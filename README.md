## Proposta e decisões da solução

Sistema de gestão para clínicas veterinárias. A Fidelis centraliza o acompanhamento de pets por clínicas e tutores, reunindo cadastro, consultas, vacinação, vermifugação e histórico clínico. A interface web oferece fluxos dedicados por perfil, enquanto a API REST dá suporte às operações administrativas. As regras de negócio evitam conflitos de consultas da mesma clínica no mesmo horário e destacam pets sem acompanhamento recente.
